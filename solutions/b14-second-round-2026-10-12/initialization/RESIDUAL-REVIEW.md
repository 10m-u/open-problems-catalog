# Independent review of P2 endpoint-pair compression

**Verdict:** the state-equivalence theorem in [residual-search/RESULT.md](../residual-search/RESULT.md) and its implementation in [hamilton_dp.py](../residual-search/hamilton_dp.py) pass internal review. The measured reduction 14,808→13,932 retained states is supported. This completes the stated state-compression deliverable; it does not resolve the programme's broader faster-search ambition.

After excluding a prematurely closed cycle, every nonisolated prefix component is a path: maximum degree two plus acyclicity implies this. Each path has exactly two degree-one endpoints, and neither endpoint can have been forgotten because forgetting requires degree two. All forgotten vertices have their final required degree. A degree-two boundary vertex cannot accept any suffix edge. Suppressing each prefix path to its endpoint pair thus preserves every possible suffix attachment, cycle closure and connectivity decision, even when saturated vertices belong to different paths in two prefixes. The introduced/forgotten vertex sets are fixed by the processing position. Equal boundary degrees and endpoint pairs therefore determine identical feasible suffixes; their added costs coincide, so minimum-prefix aggregation is exact.

The implementation detects cycle closure using endpoint component equality **before** clearing saturated labels. Joining different paths transfers the common label to the surviving endpoints; joining the same path closes a cycle. The all-city test requires every vertex already introduced and every active degree equal to two, so an accepted closure cannot leave another path or an unvisited vertex. Its terminal state permits only omitted suffix edges. New degree-zero vertices receive fresh component labels only upon taking an incident edge; taking from a saturated vertex is rejected before those labels matter.

The lower-degree feasibility rule d(v)+remaining(v)≥2 is necessary. At equality, the omitted-edge branch will fail this check, implementing the forced-edge implication. Incumbent pruning by current prefix cost is safe under the packet's **nonnegative-cost** assumption. The public function does not validate that assumption; callers supplying negative costs should omit `upper` or add input validation. The compression theorem itself does not require nonnegative costs when no such pruning is used.

The state-count formula correctly chooses the degree-one set, its perfect matching, and degree zero/two for the remaining boundary vertices. It is an upper bound and may count unreachable keys. Copying complete witnesses has the separately acknowledged edge-count overhead.

The parent [check.py](../residual-search/check.py) compares full histories, full component partitions and endpoint pairs against independent metric subset DP, and re-verifies the sixteen source residual certificates. I checked its receipt totals and added [independent literal controls](check_final_reviews.py): all 1,024 simple graphs on five labeled vertices agree with a permutation-tour oracle for all three solver modes, with zero/tied/positive costs. Literal suffix enumeration on two edge schedules checks 137 colliding-key groups and 6,518 pairwise suffix comparisons; twelve groups have genuinely different saturated component assignments. All completions agree. [Receipt](FINAL-REVIEW-CHECK-RESULTS.json).

The measured frontier method remains slower by transition count than subset DP on the cited bounded instances. No performance extrapolation, residual treewidth bound, novelty claim or external peer review follows from this correctness review.
