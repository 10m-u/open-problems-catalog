# Sources

2286 primary documents (dissertations and papers) are cited by the problems in this repository, plus 2536 further references (later preprints and follow-on work) linked from the problem pages. Texts are not included, because most are under copyright. To download them for your own use, run `python3 tools/fetch_sources.py` (see [tools](../tools/README.md)). The full list is also in [`data/sources.json`](../data/sources.json), which includes the further references.
